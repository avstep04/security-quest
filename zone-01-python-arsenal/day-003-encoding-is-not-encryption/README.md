## Results

**Encoding vs encryption vs hashing**
| Type | Reversible? | Needs a key? | Purpose |
|---|---|---|---|
| Encoding | Yes, by anyone | No | Moving data through systems safely |
| Encryption | Only with the key | Yes | Keeping data secret |
| Hashing | No | No | Fingerprinting and verifying data |

Encoding hides nothing. Anyone can reverse it in seconds.

**CyberChef and decoder.py:** both decoded all five challenges the same way

|---|---|---|

## What I learned
- Encoding is for transport, not security. Base64 "protection" is a red flag.
- Attackers stack encodings to slip past filters. Analysts peel them back one layer at a time.
- A decoder should try the strictest check first (hex before Base64) and confirm the result is readable text.
- ROT13 can't be detected automatically. A person has to judge whether the guess makes sense.

## Key notes
### New today
| Term | What it does |
|---|---|
| Base64 | Encoding that turns any data into letters, digits, `+` and `/`, often ending in `=` |
| Hex encoding | Writes each byte as two characters, 0–9 and a–f |
| URL encoding | Replaces special characters with `%` codes, like `%20` for a space |
| ROT13 | Shifts each letter 13 places; doing it twice gets the original back |
| CyberChef | GCHQ's free browser tool for decoding, built from drag-in "recipes" |
| Magic (CyberChef) | Operation that guesses an encoding automatically |
| `import base64` | Loads Python's Base64 library |
| `base64.b64encode()` | Turns bytes into Base64 |
| `base64.b64decode(s, validate=True)` | Turns Base64 back into bytes; `validate` rejects invalid input |
| `.decode()` | Turns bytes back into text; the opposite of `.encode()` |
| `bytes.fromhex()` | Turns a hex string into bytes |
| `import codecs` | Loads Python's library of text conversions |
| `codecs.encode(s, "rot13")` | Applies ROT13 to text |
| `import urllib.parse` | Loads Python's URL tools |
| `urllib.parse.unquote()` | Turns `%` codes back into normal characters |
| `import binascii` | Loads the library behind Base64 and hex; provides `binascii.Error` |
| `try:` / `except (...):` | Attempts code and catches the listed errors instead of crashing |
| `ValueError` / `UnicodeDecodeError` | Errors for bad input and for bytes that aren't valid text |
| `None` | Python's "no value"; here it means "this decoder didn't work" |
| `pass` | Placeholder line that does nothing |
| `.isprintable()` | True if every character in the text is a normal, visible character |
| `and` | True only if both sides are true |
| `"x" in s` / `not in` | Checks whether some text appears inside a string |
| `for name, fn in [...]:` | Loops over a list of pairs, here a name and a function |
| `range(1, 6)` | Counts 1 through 5 (the end number is excluded) |
| `a if condition else b` | One-line if/else that picks a value |
| `name, out = f()` | Unpacks a function that returns two values |
| `--help` | Shows a script's usage text, generated by argparse |
